# 시간 구간별 사용량 집계 수정

`usage.py`의 `total_bytes(events, start, end)`는 각 이벤트의 `at` 시각과 `bytes` 값을 받아 구간 안의 바이트 합계를 정수로 반환합니다. 연속된 두 구간을 집계하면 경계에 걸친 이벤트가 잘못 계산될 수 있습니다.

시작 시각을 포함하고 종료 시각을 제외하도록 수정해 주세요. 모든 시각은 UTC 오프셋이 있는 ISO 8601 문자열입니다. 표기한 오프셋이 달라도 같은 순간은 동일하게 처리하고, 날짜가 바뀌는 경우에도 이 규칙을 적용합니다. 같은 시각의 여러 이벤트는 각각 한 번씩 더하며 입력 순서와 무관해야 합니다. 빈 구간은 0을 반환합니다. 공개 함수의 호출 방식과 기존 정상 사례를 유지하고 회귀 테스트를 추가해 주세요.
